# 🌟 Overview

**ReMarket** is a MERN Stack web platform for buying and selling pre-owned electronic devices.

The platform connects buyers and sellers through a clean, secure marketplace that promotes affordable technology and sustainable reuse of electronics.

---

# ✨ Key Features

- 📱 Product Listings
- 🔍 Advanced Search & Filters
- 👤 User Authentication
- ❤️ Wishlist
- 🛒 Shopping Experience
- 💬 Buyer & Seller Communication
- 📷 Multiple Product Images
- 📍 Category Browsing
- 📊 Seller Dashboard
- 🔐 Secure Access

---

# 🏗️ System Architecture

```text
             Client (React)
                    │
        Authentication (JWT)
                    │
          Express REST API
                    │
       Business Logic Layer
                    │
      MongoDB Database
```
